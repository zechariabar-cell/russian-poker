# פוקר רוסי - שולחן חברים

משחק Russian Poker (בסגנון Caribbean Stud) עם שולחן משותף בזמן אמת. שבבים וירטואליים בלבד.

## הרצה מקומית

    npm install
    npm start

ואז לפתוח http://localhost:3000

## העלאה לאינטרנט (Render, חינמי)

1. להעלות את התיקייה ל-GitHub (repository חדש).
2. ב-render.com: New + > Web Service > לחבר את ה-repository.
3. Runtime: Node. Build Command: `npm install`. Start Command: `npm start`. Instance Type: Free.
4. אחרי הפריסה מתקבלת כתובת בסגנון https://שם.onrender.com - זה הקישור לשלוח לחברים.
5. בתוך השולחן יש כפתור "העתק קישור הזמנה" שכולל את קוד החדר.

הערה: בתוכנית החינמית השרת "נרדם" אחרי כמה דקות בלי פעילות, והכניסה הראשונה אחריו לוקחת כחצי דקה. מצב המשחק נשמר בזיכרון בלבד, ולכן הפעלה מחדש של השרת מאפסת שבבים וחדרים.

## מבנה

- `server.js` - שרת HTTP ו-WebSocket, חדרים, סבבים.
- `game.js` - חפיסה, דירוג ידיים, חישוב תשלומים.
- `index.html` - כל הממשק (עברית, RTL).

## חוקים

- Ante מינימלי 10. חייבים שבבים גם ל-BET (פי 2), ולכן ה-Ante המקסימלי הוא שליש מהשבבים (פחות ה-Bonus).
- הדילר מוכשר עם A-K ומעלה. אם לא מוכשר: Ante משלם 1 ל-1 וה-BET חוזר.
- תשלום על BET: A-K או זוג 1:1, שני זוגות 2:1, שלשה 3:1, סטרייט 4:1, פלאש 5:1, פול האוס 7:1, רביעייה 20:1, סטרייט פלאש 50:1, רויאל פלאש 100:1.
- Bonus Bet (אופציונלי, מינימום 10): לפי 5 הקלפים הראשונים, בלי קשר לדילר. שלשה 5:1, סטרייט 50:1, פלאש 100:1, פול האוס 150:1, רביעייה 250:1, סטרייט פלאש 800:1, רויאל פלאש 1500:1.
- DRAW: Ante אחד להחלפת 1 עד 5 קלפים. BUY: Ante אחד לקלף שישי. מותר גם וגם, פעם אחת מכל סוג. עם 6 קלפים נספרת היד הטובה ביותר מתוך 5.
- מי שעושה FOLD מפסיד את ה-Ante ואת מה ששילם על DRAW ו-BUY.
- כל שחקן מקבל 1000 שבבים בכניסה, ואפשר לקבל 1000 חדשים כשנגמר.
- Insurance ויד שנייה לא ממומשים.
